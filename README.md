# Baby Store Website Clone

A responsive baby products shopping website built using HTML, CSS, Bootstrap, and JavaScript.

## Live Demo
- **Netlify:** https://incandescent-yeot-423d2f.netlify.app/
- **GitHub Pages:** https://anushkamate14.github.io/Baby-Store-Website-Clone/

## Project Overview
A frontend web development project designed to provide a user-friendly shopping experience for baby products.

## Technologies Used
- HTML5
- CSS3
- Bootstrap
- JavaScript
- JSON (where applicable)

## Website Pages
- Home
- Shop
- Product Details
- Cart
- Checkout
- About Us
- Contact
- Testimonials

## Key Features
- Responsive website layout
- Product browsing interface
- Interactive UI elements
- SEO meta tags and social sharing previews
- Sitemap and robots.txt
- Website deployment using Netlify and GitHub Pages

## Project Structure
- `CSS/` — Stylesheets
- `Images/` — Website images and visual assets
- `JS/` — JavaScript files
- HTML files — Website pages

## Run Locally
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser or use the Live Server extension.
